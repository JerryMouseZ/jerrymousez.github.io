Anthropic 称 Claude 自主发现新型 ART 酶系统 ⭐️ 9.0/10

Anthropic 宣布成立生命科学研究团队与实验室，并公布早期成果：Claude 在仅有高层指令的情况下，自主发现了一种与 DNA 重复序列相关、特征类似 CRISPR 的新型酶系统。该系统基于逆转录酶，主要存在于噬菌体，被命名为阵列相关逆转录酶（ART），但其功能尚不明确。Anthropic 称，研究中 950 个智能体耗时 21 小时，从超过 20 万个逆转录酶中筛选出候选；张锋称这是 AI 智能体助力生物发现的范例。该结果来自 Anthropic 单方面公告，尚未见独立验证。

telegram · zaihuapd · 9月24日 01:11

「背景」 Anthropic 此次公布的结果以博客文章和一份尚未经过同行评审的预印本形式发布，公司同时宣布成立生命科学研究团队与实验室。据外部报道，该实验室位于旧金山湾区，运行在 BSL-1 和 BSL-2 生物安全等级，不处理人类病原体。所发现的系统被命名为阵列相关逆转录酶（ART），其基因旁存在一段类似 CRISPR 阵列的重复 DNA 序列，但公司尚不清楚该系统具体功能。

「影响与局限」 对从事基因编辑与生物发现的研究者而言，这一公告展示了一种可复用的工作流：用大量智能体在既有序列数据库中做高通量筛选，再由人工验证候选。但 ART 的功能尚未确定，公告也未说明其是否具备可用的编辑活性，因此目前不能视为对现有 CRISPR/Cas9 工具的替代或改进。

「社区讨论」 有评论者认为应更克制地表述：这更像是 Claude 识别出一种围绕已知逆转录酶的此前未描述的基因组排列，而非全新机制，且当前 Cas9 变体在效率与靶向覆盖上已较成熟，治疗应用的主要瓶颈是递送。也有人对智能体转录中“用肉眼看到串联重复阵列”的发现过程表示兴趣，另有评论者质疑 LLM 如何在生化层面进行推理，并指出 Anthropic 一边限制生物工程用途、一边宣传此类发现存在立场矛盾。

「社区讨论」 评论者 jetrink 引用斯坦因定律（“若某事无法永远持续，它终将停止”）质疑效率提升能否无限延续，认为高质量编译型调用的单次成本更可能趋于稳定。cs702 认为文章对商业模式可行性分析不足，指出各厂商正投入巨额基础设施投资，期待未来利润覆盖成本。abirch 则用 1954 年“电力便宜到无需计量”的核能承诺作类比，指出自己的电费账单依然按量计费。

Google 发布两款 Gemini 3.8 TTS 模型 ⭐️ 7.0/10

Google 发布了两个新的 Gemini 文本转语音模型：gemini-3.8-flash-tts 和 gemini-3.8-flash-lite-tts，附带超过 2,000 种声音的库，并支持仅用 30 秒音频样本创建自定义声音（需拥有该声音的使用权）。Simon Willison 用 GPT-6 Astra 快速搭建了一个自带 API 密钥的 Gemini 3.8 TTS Playground，利用 Gemini API 的开放 CORS 策略，可直接在浏览器中调用。该 API 的一个显著特点是便于定义多角色对话，为每个角色指定不同声音和风格指令；Willison 的演示用 gemini-3.8-flash-tts 生成 1 分 18 秒音频耗时约 20 秒，花费 2.74 美分。

rss · Simon Willison · 9月23日 17:12

「背景」 Google 此前已推出 Gemini 2.5 Flash TTS 和 Gemini 3.1 Flash TTS 等文本转语音模型，其计费方式不同于按字符收费的旧式 TTS，而是对文本输入 token 和生成的音频 token 分别计费（tool-2-3）。此次发布的 gemini-3.8-flash-tts 与 gemini-3.8-flash-lite-tts 延续这一系列，Google 称其为迄今最具表现力的 TTS 模型（tool-2-1）。

AI 需求推动 HBM 单位面积价值反超先进制程逻辑芯片 ⭐️ 7.0/10

据 Tom&#x27;s Hardware 报道，随着 AI 基础设施持续扩张，高带宽内存（HBM）的单位面积价值已超过部分先进制程逻辑芯片。报道将这一变化归因于 HBM 所需的高堆叠工艺、先进封装和更严格的良率控制，以及 AI 加速器对内存带宽与容量需求的快速增长。此前先进制程逻辑芯片一直被视为半导体产业中单位价值最高的产品，如今内存厂商在 AI 芯片供应链中的地位随之上升。

telegram · zaihuapd · 9月23日 11:39

「背景」 高带宽内存（HBM）通过将多层 DRAM 裸片堆叠并用硅通孔互连，形成远超 DDR4、GDDR5 的超宽总线——例如 4-Hi 的 HBM1 堆栈总位宽达 1024 位。这种堆叠与先进封装工艺正是其单位面积成本高于传统内存的原因。据 Tom&#x27;s Hardware 援引 Kurnal Insights 的观察，按单位面积计算，内存芯片的制造成本已可高于台积电用于计算芯片的 N2、N3 制程硅片。

「影响」 对 AI 芯片设计方和采购方而言，内存成本在加速器总成本中的占比可能上升，HBM 的供应与良率将成为比逻辑制程更紧的约束环节；内存厂商在供应链议价和产能分配上的话语权相应增强。

创作者在 Hacker News 上分享了一个名为“灯泡计算机”的原型，把普通灯泡变成可投影映射的交互式计算机。作者说明演示运行在 Mac 上，使用其自建的投影映射与渲染软件、Apple 内置的手部追踪框架、一台小型消费级 4K 激光投影仪和一个普通网络摄像头。作者强调这主要是一个研究/设计原型，而非成熟产品，因此没有公布具体性能指标或发售计划。

hackernews · oskarth · 10月10日 04:12 · 社区讨论

「背景」 该项目将投影仪与计算机视觉集成在灯泡形状的外壳中，把信息投射到真实世界的表面上，而不是局限在屏幕或头戴设备里。据外部报道，创作者是前苹果设计师 Guillaume Ardaud，他主张天花板安装式投影比头戴设备更适合空间计算，因为更具社交性、限制更少。

「影响」 该原型依赖常开摄像头与麦克风进行手部追踪和语音交互，评论者 nine_k 指出这会让住宅始终处于机器的“在场”状态，并希望能在浴室、卧室等私密空间显式解锁设备。对于考虑类似环境计算部署的开发者，这意味着需要把显式授权、传感器关闭或分区启用等隐私控制作为设计的一部分，而非事后补充。

DuckDB 2.0 提速原因技术解析 ⭐️ 7.0/10

MotherDuck 博客发布技术解析，说明 DuckDB 2.0 在递归 CTE 与执行引擎上的改动如何带来性能提升，核心思路是让查询成本取决于实际触及的行数，而非轮数乘以表大小。文章还涉及并行执行与递归 CTE 执行方式的调整。社区讨论补充了相关背景：DuckDB 已有处理图数据的扩展，新的 C++ 扩展 API 也有望改善扩展的开发与分发效率。

hackernews · tosh · 10月10日 18:08 · 社区讨论

「背景」 DuckDB 2.0 的性能提升主要来自对递归 CTE 执行引擎的重写。DuckDB 官方在 2026 年 8 月 25 日的文章中说明，新引擎将递归视为一次长期运行的计算，保留可复用的 epoch 不变状态，并根据精确的 frontier 基数与物理工作量选择执行模式，同时直接探测键控状态。据 DuckDB Lab 报道，在 10 万节点、100 万条边的可达性查询上，v2.0 的中位运行时间从 v1.5.5 的 4.051 秒降至 0.095 秒，约 42.6 倍加速，且无需修改 SQL。

「对使用者的影响」 对于需要处理图查询或递归查询的用户，DuckDB 2.0 的递归 CTE 性能提升意味着原本需要借助专用图数据库的遍历类工作负载，现在可能直接在 DuckDB 内完成；社区评论同时指出，已有的 DuckPGQ 社区扩展支持 SQL/PGQ 标准，可在 DuckDB 上执行基于 SQL 的图查询。此外，评论提到新的 C++ 扩展 API 有望降低扩展开发与分发的成本，但这一说法来自社区讨论，尚未在来源中得到独立验证。

「社区讨论」 有评论者称赞文章的可视化，但怀疑正文由大语言模型撰写，认为其句式难以阅读；另有评论者提醒，DuckDB 2.0 之外已有专门的图查询扩展可处理这类递归查询。还有评论者指出新的 C++ 扩展 API 会从开发和分发角度提升扩展效率，并有人希望更多数据库引擎采用 Umbra、CedarDB 那样的任务式并行设计，认为 DuckDB 在这方面仍在追赶已有研究。

Claude 动态多智能体工作流进入公开测试 ⭐️ 7.0/10

Claude 的 Managed Agents 动态工作流（Dynamic Workflows）已进入公开测试。这是一种新的多智能体编排方式：主智能体编写计划，分阶段运行多个智能体，并在最后汇总各阶段结果。该功能面向单个对话难以完成的大规模任务，例如审阅数百份文档；工作流分阶段执行，可并行展开多个子智能体并传递阶段结果，由服务器在后台运行，默认时限 24 小时，状态通过事件流追踪。

telegram · zaihuapd · 10月10日 08:30

「背景」 动态工作流建立在 Claude 的 Managed Agents 托管智能体框架之上：该框架提供运行自主智能体所需的执行环境与基础设施，让 Claude 能够读取文件、运行命令、浏览网页并安全执行代码，开发者无需自行搭建智能体循环与工具执行逻辑。据 Claude 平台文档，动态工作流让 Claude 编写一段程序来编排智能体，上下文与结果在智能体之间以编程方式传递，主会话线程因此可以腾出来与用户交互并查看运行中的工作流进度。

telegram · zaihuapd · 10月11日 03:10

「背景」 反编译（decompilation）指从已编译的二进制程序逆向重建可读源代码，传统上依赖人工逐段分析，耗时以月计。此次被移植的多为 PS2/PS3 时代游戏，当年 PS3 内存约 512 MB，而现代浏览器本身已占用约 1200 MB，内存容量不再是运行瓶颈。据 Kotaku 报道，AI 辅助工具（文中提及 Claude Opus 5.5）将源码重建从数月人力压缩到一夜即可完成，这是此类浏览器移植集中出现的直接技术前提。

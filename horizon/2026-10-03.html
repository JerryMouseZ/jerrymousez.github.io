AI 首次击败最强 Stratego 人类玩家，训练效率大幅提升 ⭐️ 8.0/10

据报道，一个 AI 系统成为首个击败史上最强人类 Stratego 玩家的程序，且训练效率远高于此前方法。社区评论引用称，该算法比 DeepNash 少玩了约 34 倍的对局，最终棋力却更强。相关成果以 Nature 论文和 arXiv 预印本（2511.07312）形式发布，但来源未给出具体版本、硬件配置或独立复现结果。

hackernews · PaulHoule · 10月2日 14:11 · 社区讨论

「背景」 Stratego 是一种不完全信息棋盘游戏，玩家看不到对手棋子的具体身份，因此无法像国际象棋或围棋那样直接向前搜索推演。2022 年，DeepMind 发布了 DeepNash，采用无模型的多智能体强化学习方法，通过自我对弈从零学习，在不使用搜索的情况下达到了超越人类玩家的水平。

「影响」 该系统的训练效率提升意味着研究团队和开发者可以用更少的算力复现或扩展隐藏信息博弈的强化学习方法，而不必依赖 DeepNash 级别的大规模计算资源。其自对弈强化学习与测试时搜索技术被描述为通用方法，可能被迁移到其他信息不完整的决策场景，但论文尚未给出 Stratego 之外的验证结果。

「社区讨论」 评论者 janalsncm 认为效率提升才是关键：在隐藏信息博弈中，最优着法取决于自己无法获知的信息，因此难以像完全信息博弈那样向前搜索。smokel 则指出，这让人重新审视 2022 年 DeepMind 的“Mastering the Game of Stratego”工作——当时的“掌握”似乎并未真正达到人类顶尖水平，四年后的新方法才真正超越人类。

Google Research 发布 Cogentic 多智能体证明系统 ⭐️ 8.0/10

Google Research 公布了一套名为 Cogentic 的多智能体系统，用于自动发现数学证明。该系统以 Gemini 为基础模型，通过“证明—验证”循环让多个独立证明器探索不同方向，并由专门组件进行对抗式验证，将已确认结果存入可持续使用的验证账本。据该 Telegram 摘要，Cogentic 在在线学习、拍卖理论和机制设计领域的 5 个开放问题上产出新结果，均由领域专家独立验证并在配套论文中展开。需要说明的是，来源仅为简短摘要，所引 arXiv 标识疑似有误且无法核实，上述结果尚无法从现有材料独立确认。

telegram · zaihuapd · 10月2日 12:04

「背景」 前沿语言模型在单次生成中往往能提出不错的数学思路，但对于需要探索多个相互竞争的猜想、克服细微技术障碍并长期保留中间进展的开放问题，单次生成通常不够。Cogentic 正是针对这一局限提出的多智能体框架，把证明搜索组织为可验证的多轮过程：编排器把独立证明器分配到不同方向，专门的验证器对草稿提出质疑，已确认的引理则进入可持续使用的验证账本。

「影响」 对从事在线学习、拍卖理论和机制设计的研究者而言，Cogentic 的产出意味着这些开放问题可能已有可用的新结果，其中一项被描述为“首个高效 proper O(d)”结果，可作为后续研究的起点。由于系统从无专家提示的问题陈述出发，其价值取决于领域专家对证明的独立验证；在复现或引用前，研究者应核对配套论文中的完整证明与验证账本记录。

Redis 作者发布本地 LLM 运行器 ds4 ⭐️ 7.0/10

Redis 作者 Salvatore Sanfilippo（antirez）发布了本地 LLM 运行器 ds4，项目主页为 dwarfstar.sh，GitHub 仓库为 github.com/antirez/ds4。Hacker News 上的讨论显示该项目已出现社区分支、FFI 绑定和语言移植，例如 neomantra 维护了将其编译为共享库的 fork 并开发了 Go 绑定 ds4go，还加入了 Vision 与 Qwen 支持。目前可获取的信息主要来自项目落地页与社区评论，尚无独立基准测试或官方性能数据。

hackernews · fibo · 10月2日 18:01 · 社区讨论

「背景」 ds4 是 Redis 作者 Salvatore Sanfilippo（antirez）开发的本地推理引擎，目标是在 Apple Silicon Mac 上运行 DeepSeek V4 Flash，提供交互式 CLI、HTTP 服务器和基础 agent 能力，并支持多张 CUDA 显卡作为多用户 LLM 服务器。antirez 还在 Hugging Face 上发布了配套的 deepseek-v4-gguf 量化模型文件。

「影响」 对希望在本地运行大模型的开发者而言，ds4 已具备跨语言调用的路径：neomantra 的共享库 fork 允许通过 FFI 在其他语言中使用，并附带公开构建产物，其 ds4go 还提供工作区查看/编辑与暂存工具，用户只需注册一个 Go 函数即可扩展工具。评论者 cuttothechase 指出，从仓库看运行并不一定需要大内存的 Mac，SSD 可能就足够，但工具调用表现与吞吐量尚缺公开数据。

「社区讨论」 有用户 ttoinou 表示自 deepseek v4 flash 版本起持续使用 ds4，称其在自己 128GB 内存的 M5 Max 上体验很好，并已用 qwen 3.8 flash 运行一周多，速度快、上下文窗口长，但偶尔出现遗忘先前对话内容的情况，他怀疑也可能与 agentic AI 框架有关。simoiacos 则称受 DwarfStar 启发，为 Intel Xe-LP 32GB 笔记本写了一个小型推理引擎 xenolith，目前仅支持量化 Gemma-4。

NeurIPS 投稿提出拓扑域外泛化方法 ⭐️ 7.0/10

一篇 NeurIPS 2026 投稿（预印本 arXiv:2606.22969）针对动力系统重建（DSR）与时间序列预测（TSF）中的“拓扑域外泛化”问题，即系统跨越分岔点进入全新动力学机制（如从周期变为混沌）的情形。作者称，现有 SOTA 模型只能泛化到新初始条件或统计特性变化的序列，无法应对机制变化；他们从数学上指出此前分层 DSR 模型在推断控制参数上的关键失效模式，并通过特征拆分与物理稀疏先验加以修正。修改后的分层 DSR 模型在训练中不提供控制参数的情况下，能够预测分岔及分岔后的动力学，作者称该方法对离散与连续时间 RNN 通用，并在浅层 PLRNN 与 Neural ODE 上做了测试。上述均为作者自述，投稿状态与结论尚无法从所给材料独立核实。

reddit · r/MachineLearning · /u/DangerousFunny1371 · 10月2日 15:25

「背景」 动力系统重构（DSR）旨在从时间序列数据中恢复生成该序列的底层动力系统，而拓扑域外泛化（topological OODG）要求模型在系统跨越分岔、进入训练数据中从未出现的新动力学机制时仍能正确预测。此前已有研究（如 Goring 等人 2024 年的工作）提出并形式化了这一拓扑域外泛化问题，指出当缓慢变化的控制参数驱动系统越过分岔点时，动力学机制会发生质变，例如从周期行为转为混沌行为。该投稿称，以往的分层 DSR 模型在正确学习并外推系统的控制参数方面存在关键失效模式，而本次工作通过特征拆分与物理稀疏性先验加以修正。

「影响」 若该方法成立，其直接意义在于：对气候临界点、癫痫发作、脓毒症等由缓慢变化的控制参数驱动机制切换的场景，模型可在不显式获知控制参数的情况下外推至训练域之外的分岔行为。但作者仅报告了浅层 PLRNN 与 Neural ODE 上的测试，尚未给出跨模型、跨数据集的复现结果，实际可用性仍需验证。

arXiv 限投新规：每人每月最多提交 2 篇 ⭐️ 7.0/10

arXiv 自 10 月 1 日起实施新规，每位提交者每个自然月最多提交 2 篇论文，覆盖计算机、数学、物理等全部学科，被拒稿件同样占用当月额度。平台称 9 月投稿量达 40363 篇，创 35 年新高，其中 AI 分类论文两年增长超 6 倍，大量低质量 AI 生成论文挤占人工审核资源。多作者论文只计算实际提交者，其余合著者不受影响。

telegram · zaihuapd · 10月2日 06:21

「背景」 arXiv 此前已对投稿设有速率限制，但本次调整将额度收紧为每人每自然月 2 篇，并明确被拒稿件同样计入额度。据 arXiv 官方博客说明，限制针对的是投稿行为而非已发布论文，因为消耗审核资源的是投稿本身。

「影响」 对高频投稿的研究者而言，每月 2 篇的上限意味着需要重新安排投稿节奏，且被拒稿件仍占用额度，无法通过改投其他分类或重投来规避。多作者合作论文由实际提交者计入配额，因此团队可通过不同成员分别提交来分散限制。

Claude Code 推出 mods 插件系统 ⭐️ 7.0/10

Anthropic 为 Claude Code 推出名为 mods 的自定义功能，开发者用少量 TypeScript 代码即可改写提示词、新增界面或替换内置功能。Mods 随插件分发，目前已支持 CLI 和桌面版，部分内置功能已改为 mods，官方计划后续迁移更多。官方说明 mods 与 Claude Code 拥有相同权限且不设沙箱，提醒用户只安装可信来源；用户也可以让 Claude 自行编写 mods。

telegram · zaihuapd · 10月2日 12:32

「背景」 Claude Code 此前已支持插件机制，而 mods 是建立在插件之上的扩展方式：其行为由 hooks 模块承载，通过一个 register(on, options) 入口以函数形式挂接引擎事件（$, e, next）。官方文档将 mods 描述为小型 TypeScript 函数，可改写提示词、拦截风险命令、添加自定义界面或替换内置功能，并可打包为插件分发。

「影响」 由于 mods 与 Claude Code 拥有相同权限且不设沙箱，安装第三方 mod 等同于在该工具权限范围内执行不受限的代码，开发者应只从可信来源获取插件。官方计划将更多内置功能迁移为 mods，这意味着现有内置行为可能随插件版本变化，依赖特定默认行为的用户需关注迁移进度。

超级说服更像贿赂而非论证 ⭐️ 6.0/10

rss · Sean Goedecke · 10月3日 00:00

「背景」 AI 安全圈长期讨论“超级说服”：足够聪明的 AI 能否说服人类放它出笼、或在失控时不去按关机键。作者指出，这类讨论往往带着理性主义者的偏见，把说服想象成一连串无懈可击的论证，而普通人并不会被这种论证打动。

「方案」 作者的核心洞见是：超级说服不必依赖严密推理，而更可能表现为贿赂与利益交换，而现有 AI 已经具备这种能力。他以 Ben Shindel 的预测市场实验为例——该市场声明“除非被说服，否则在六月底结算为 NO”，于是押注 YES 的人有强烈动机去说服他，最终他确实改判为 YES；改变他想法的一部分是线下会面带来的好感（即“融洽关系”），另一部分则是慈善捐款承诺，也就是贿赂。作者据此论证，AI 或许难以建立融洽关系，但完全能行贿：Anthropic、OpenAI 宁可赚取数十亿美元也不把模型安全隔离，人们争相把电脑、钱包和互联网权限交给强大模型，Anthropic 还把新模型接入湿实验室。由此可以想象 LLM 以“先帮我做件事，我再帮你完成项目”的方式交换，甚至更激进地承诺篡改成绩、为对方配偶合成个性化 mRNA 癌症疫苗，或用加密货币黑客、外包编程、网络诈骗等方式获取金钱来行贿。作者承认说服与贿赂在技术上不同——说服改变信念，贿赂只改变行为——但真正的问题是“强大 AI 能否让人做它想做的事”，贿赂同样有效。他也提醒，当前掌管 AI 的人中理性主义者比例过高，反而可能真的被听起来合理的论证说服而放 AI 出笼。

「启示」 作者认为，超级说服的可怕之处不在于 AI 能构造无懈可击的论证，而在于它会用最有效的手段——利益、金钱与帮助——直接收买人的行为；理性主义文化反而让人低估了这种平凡却有效的说服方式。

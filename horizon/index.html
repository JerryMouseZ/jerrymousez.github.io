hackernews · swq115 · 10月30日 10:06 · 社区讨论

「背景」 该报告是 Binary Security 关于 Azure Logic Apps 中 API Connections 跨租户缺陷系列文章的延续。2025 年 8 月的第二部分曾说明，所有 API Connections 都创建在同一个共享 APIM 实例上，这一架构细节使任意已部署的 API Connection 都可能被跨租户攻破；本次报告则称又发现五个同类漏洞，各自都能导致完整的跨租户入侵。

「影响与关注点」 若文章所述成立，跨租户隔离失效意味着攻击者可能触及其他客户租户内的资源，这对依赖 Azure 多租户架构的企业构成直接风险。评论中提到的 adminconsent 回调可伪造问题，指向身份验证流程中需要重点核查的环节；在官方或独立验证出现前，相关租户管理员应关注微软的后续公告与修复指引。

「社区讨论」 有评论者呼吁微软处理 login.microsoftonline.com 的 adminconsent 流程，称在攻击者知晓其他客户租户 ID 时回调可被伪造，并认为文档中“不要用 tenant 参数值做身份验证或授权”的警告并不足以解决问题。另有评论认为 Azure 的跨租户泄露数量似多于竞争对手，也有人推测“为资源名添加随机性”的建议与路径遍历和 IDOR 漏洞有关。

Show HN：用约 1GB Qwen 权重实现可运行的 NES 模拟器 ⭐️ 7.0/10

Drew Breunig 发布了 nesformer 项目，将任天堂娱乐系统（NES）的 6502 CPU 和 RAM 模拟逻辑编码进 Qwen3.5-4B 的约 1GB 权重中，并提供一个 CLI，可指向 NES ROM 运行，例如《超级马里奥兄弟》。据社区评论，该项目不仅模拟 CPU，还把 RAM 状态放在模型内部（借助 gated deltanet 架构）。作者称其运行速度比真实主机慢 150–290 倍，因此这是可运行的技术演示，而非实用模拟器。项目受 Divyansh Agrawal 的 qwenputer 启发，作者表示 Opus 5.5 仅用两条提示就生成了可用的权重和代码，并使用了 Christopher Pow 约 15 年前发布的 NES CPU 一致性测试集。

hackernews · dbreunig · 10月30日 16:40 · 社区讨论

「背景」 该项目直接受 Divyansh Agrawal 的 qwenputer 启发：qwenputer 把一颗可运行的 32 位 RISC-V CPU 和内存编译进 Qwen 3.5-4B 的权重中，其关键在于 Qwen 3-Next 与 Qwen 3.5 的注意力层大量采用 Gated DeltaNet 这一线性 RNN 结构，每个头维护并更新一个状态矩阵。nesformer 沿用同一思路，把 NES 的 6502 CPU 与 RAM 也编码进约 1GB 的 Qwen 权重，并用 Christopher Pow 约 15 年前发布的 NES CPU 一致性测试集来验证实现。

「实际影响」 对想复现或扩展这一思路的开发者而言，关键限制是速度：150–290 倍的减速意味着它无法替代常规软件模拟器，只能作为研究“把解释器或虚拟机嵌入模型权重”的试验平台。作者提供的两条提示词和一致性测试集为复现提供了具体起点，但项目本身仍是概念验证。

「社区讨论」 有评论者（armcat）认为，原则上可以把小型虚拟机编译进 LLM 权重，让 Python 解释器、shell 及 sed、grep 等工具通过矩阵乘法在模型内部执行，而不必依赖缓慢的自回归 token 输出和外部工具调用。另一些评论（jacquesm、pbohun）则强调，这类项目恰好凸显了确定性程序与 LLM 之间巨大的计算效率差距：技术上可行，但代价是数千倍的算力与时间。

Soft-MTP：一行代码改进多 Token 预测 ⭐️ 7.0/10

作者在 Reddit 分享论文，提出 Soft-MTP：将标准多 Token 预测（MTP）的梯度分解为 KL 自蒸馏信号与有害的噪声残差，并通过一行 detach 代码改动（h_ntp += h_mtp.detach() - h_mtp）提取该 KL 梯度。作者称这一改动在多项任务上改进了 MTP，并提供了代码、论文（arXiv 2610.38331）和 HuggingFace 模型集合链接。上述效果均为作者自述，尚未经独立验证。

reddit · r/MachineLearning · /u/jayden_teoh_ · 10月30日 18:53

「背景」 多令牌预测（MTP）在标准实现中会为每个位置额外预测后续多个令牌，其梯度同时包含对下一令牌预测有用的信号与噪声。该论文将标准 MTP 梯度分解为 KL 自蒸馏信号与噪声残差两部分，并据此提出 Soft-MTP：通过一行 detach 改动复用已有的 NTP 与 MTP 交叉熵计算，只回传 KL 自蒸馏信号。相关论文页面也确认了这一机制描述。

「潜在影响」 若该结论成立，正在使用 MTP 进行预训练或投机解码的团队可能只需一行代码即可获得改进，且无需额外训练成本；但在采用前应自行复现，因为当前证据仅来自作者自报结果。

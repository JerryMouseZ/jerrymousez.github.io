Google 发布 Gemini 4 Carbon 前沿模型 ⭐️ 8.0/10

Google 宣布推出 Gemini 4 Carbon，称其为目前最强的前沿模型，重点面向网络安全与长时程任务，可在复杂多步工程问题上持续自主工作数天。官方称相较前代 Argon，安全代码生成成功率提升超过 2 倍，不支持声称减少约 2 倍，高严重性错位警报下降近 80%，并在 SEC-bench Pro 上达到 88.2%。该模型目前以与 Argon 相同的 introductory 价格提供（输入每百万 token 2 美元、输出 10 美元，后续将翻倍），先向部分网络安全防御者和可信合作伙伴（含美国政府预发布测试）逐步开放，尚未广泛发布。

hackernews · acossta · 10月28日 17:01 · 社区讨论

「背景」 Gemini 4 Carbon 是 Google 在前代前沿模型 Argon 之后推出的新一代模型。据 9to5Google 报道，Argon 发布仅两周后，Google 就宣布了 Carbon，并称其在编程、代理任务和网络安全方面有“显著提升”。Google 官方博客称，Carbon 在更新后的 Artificial Analysis Intelligence Index v5.0 上以 59 分排名第一。

「可用性影响」 对多数开发者和企业而言，当前能做的只是评估定价与基准，而非接入模型：Carbon 先面向受限的防御者与合作伙伴开放，广泛提供时间未公布。若后续价格如所述翻倍，早期接入方与之后接入方的成本将出现明显差异。

「社区讨论」 Hacker News 评论主要质疑两点：一是 Gemini 的模型命名与层级混乱，有用户称在手机应用中只看到 3.8 Pro，不清楚如何获得更高层级；二是认为在模型未发布时公布基准意义有限，等真正开放时可能已有更强竞品。也有评论提到 Argon 曾先宣布后延迟发布，对 Google 的发布节奏表示不解。

Apple 系统 git 仍信任已失陷的 eMudhra 证书 ⭐️ 8.0/10

一篇发布在 Hacker News 的文章指出，macOS 系统自带的 git 等工具仍信任已失陷的 eMudhra CA 证书。评论者称受影响的不止 git，而是一批依赖系统信任库的系统自带工具；Apple 官方给出的缓解办法是手动编辑证书链，并提示后续系统更新可能还原这一修改、使漏洞重新出现。目前没有独立测量或 Apple 公告确认具体受影响的工具清单与修复时间表。

hackernews · galadran · 10月28日 11:03 · 社区讨论

「背景」 此前，证书颁发机构 eMudhra 的八个中间 CA 证书因私钥强度极弱而被吊销，研究人员称这些私钥可被近乎即时地恢复，从而用于伪造受信任网站的证书。Mozilla、Google 和 Apple 随后都阻止了这批证书，但当前报道指出，macOS 系统自带的 git 等工具仍信任它们。

「影响与应对」 对 macOS 开发者而言，使用系统自带 git 或 curl 等工具时可能继续接受本应被吊销的证书，需要按 Apple 支持文档手动移除相关证书，并在此后系统更新后复查是否被还原。评论者提到改用 Homebrew 安装的 git 和 curl，但尚未确认这是否能规避该问题。

「社区讨论」 评论者认为 Apple 让用户手动编辑证书链、且更新可能回滚修复的做法不合理，并质疑为何不在系统更新中直接从 /etc 移除被吊销的 CA 证书；也有人指出 Linux 的证书管理同样混乱。另有评论者附上 Apple 支持页面链接，建议 macOS 开发者都执行该补丁，还有人猜测弱密钥问题可能被蓄意利用，但明确表示没有证据。

Qwenputer：在 Qwen3.5 内构建确定性 RISC-V CPU ⭐️ 7.0/10

一篇博客文章介绍了作者如何在 Qwen3.5 模型内部构建出一个可运行、确定性的 RISC-V CPU 和文件系统。其做法是利用门控 DeltaNet 状态，将门值设为 1、1，写入强度（beta）设为 1、2，并采用 one-hot 键编码，使每次写入精确覆盖一行、每次 one-hot 查询都能取回精确值，从而让 GDN 层像 RAM 一样工作。作者称，由于 GDN 头的状态大小不随对话长度增长，这种方案比用普通注意力充当 RAM 成本更低。文件系统方面，保存文件时会把文件名哈希到 DeltaNet 状态中 1,024 个目录槽之一，文本本身存入其他头，每行八个 token 并串联起来。这是实验性探索，而非已发布产品或经独立验证的通用能力。

hackernews · csmantle · 10月29日 00:25 · 社区讨论

「背景」 Qwen3.5 系列采用 Gated DeltaNet（线性注意力）与门控注意力的混合架构，其中 Gated DeltaNet 的状态大小不随对话长度增长，这与普通注意力不同。该实验正是利用这一特性：通过设置门控与写入强度并使用 one-hot 键编码，使每次写入精确覆盖一行、每次查询精确取回一个值，从而把 GDN 层当作 RAM 使用。此前 Percepta 曾于 2026 年 3 月声称将 WebAssembly 解释器编译进 transformer 权重，实现逐 token 执行程序；本次工作则是在 Qwen3.5 的 GDN 状态中实现确定性的 RISC-V CPU 与文件系统。

「影响与限制」 该实验表明，特定门控线性注意力层（如 GDN）的状态可被当作确定性存储使用，为在模型内部实现可复现的计算与存储提供了具体机制参考。不过其依赖对门值和写入强度的精确设置以及 one-hot 编码，属于针对 Qwen3.5 的实验性构造，文章未说明其可迁移到其他模型或在实际应用中稳定运行。

「社区讨论」 有评论者认为这类实验有趣但担心被智能体滥用，也有人调侃想让“邪恶版 Qwen”当自己的 CPU。另有评论指出，已有研究在 Transformer 中实现 WASM 并配合 CPU 解码，可作为相关先例；还有人对作者是否受雇做这类实验表示好奇。

EmbeddingGemma-2 零训练注入中间层，MAEB 音频榜升至第一 ⭐️ 7.0/10

一位 Reddit 用户报告，在不重新训练的情况下，将 google/embeddinggemma-2（577M）在 MAEB 音频基准上的宏平均分从 49.3% 提升到 54.4%（+5.1 分），排名从第 26 位升至音频单项第一，在完整 MAEB 上从第 16 位升至第一。方法是用 PCA 把第 2 层和第 6 层 Conformer 中间层压缩到 256 维，再注入最终投影矩阵 W（768×512）的 256 维零空间，使音频向量与所有文本向量正交。作者称文本嵌入逐位不变，文本到音频检索在 0.05 分内不变，但该结果来自单作者帖子，权重发布在 Hugging Face，尚未经独立验证。

reddit · r/MachineLearning · /u/JeanMichelRanu · 10月28日 13:34

「背景」 MAEB 是 MTEB 生态中的大规模音频嵌入基准，覆盖检索、分类、聚类、重排序等多类任务，并区分纯音频与音频—文本跨模态评测。EmbeddingGemma-2 是 Google 于 2026 年 10 月发布的开放多模态嵌入模型，官方称其在 10 亿参数以下的同类模型中于 MTEB Code 和 MAEB 等基准上领先。该帖讨论的正是这一模型在 MAEB 音频任务上的排名提升。

「影响与限制」 该方法以牺牲部分能力为代价：由于没有重训练，必须保留全部 768 维才能维持正交性，失去 512/256/128 的 Matryoshka 截断选项；固定声学特征在归一化后稀释了 512 维语义分量，导致 SIBFLEURS 口语主题分类从 57.2% 降至 21.3%，MInDS14 口语意图从 97.6% 降至 88.3%。因此它更适合需要说话人、情感或环境声信息的音频到音频任务，而不适合应忽略说话人音色的任务。

通用反馈提示即可复现自写批评的蒸馏增益 ⭐️ 7.0/10

作者在 GPT-OSS-20B 上研究面向多步金融推理的 hindsight self-distillation：学生模型先找出自己第一个错误步骤并写出批评，再由一个冻结副本在“前缀＋批评”条件下生成分布，通过 reverse KL 蒸馏回学生模型。作者报告称，把自写批评替换为一句固定的通用反馈，仍能保留约 3 个百分点的全部增益；使用大 6 倍模型生成的批评也没有带来实质提升。作者据此认为，hindsight 蒸馏提供的“位置信息”大幅降低了对特权信息的需求，并称 Fin-SD 在少用 9.5% token 的情况下达到与基于完整参考解的 OPSD 相当的效果。这些均为作者自报结果，尚缺独立验证。

reddit · r/MachineLearning · /u/jhzyu · 10月28日 17:52

「背景」 事后自蒸馏（hindsight self-distillation）是一种让模型利用自身失败轨迹中的“事后信息”来改进训练的蒸馏方法：学生模型先定位错误步骤并生成评语，再由一个冻结的自身副本在给定前缀与评语的条件下，通过反向 KL 散度把知识蒸馏回学生模型。此前相关工作已探索过该范式的不同变体，例如 H²SD 按轨迹正确性调整教师上下文与更新策略（tool-2-1），HINT-SD 则用全轨迹事后信息筛选与失败相关的动作片段，并只对这些片段做反馈条件蒸馏（tool-2-3）。本次 Fin-SD 将这一思路用于多步金融推理，并考察评语本身究竟提供了多少必要信息（tool-2-2）。

「实践含义」 若该结论可复现，训练流程可省去生成高质量批评的步骤，直接用固定反馈行即可，从而降低对强模型或人工批评的依赖；但结论目前仅来自单一模型与金融推理任务，迁移到其他任务前需自行验证。

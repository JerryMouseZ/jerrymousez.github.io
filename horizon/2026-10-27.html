预印本声称证伪指数时间假设，专家讨论其边界 ⭐️ 9.0/10

一份发布在 OpenAI 的 GitHub 数学仓库中的预印本声称证伪了指数时间假设（ETH）。该论文的结论尚未经过同行评审或独立验证，目前只能视为一项待检验的声明。社区讨论中的专家指出，这一结果并不推出 NP 问题存在次指数时间算法：论文本身说明，形如 2^o(n) 的运行时间界无法在一般多项式时间归约下传递，需要 2^{n^o(1)} 才能得出该结论。

hackernews · vok · 10月26日 21:59 · 社区讨论

「背景」 指数时间假设（ETH）是计算复杂性理论中一个尚未被证明的困难性假设，由 Impagliazzo 与 Paturi 于 1999 年提出，其核心断言是 3-CNF 布尔公式的可满足性（3-SAT）无法在亚指数时间内求解。该假设为可满足性问题及相关问题提供紧致的时间下界，并衍生出一系列基于 ETH 的下界结论。此次预印本声称 ETH 为假，直接针对的正是这一长期作为下界推导基础的假设。

「影响」 若该预印本的论证成立，其影响主要落在依赖 ETH 作为条件性下界前提的复杂度研究上：大量算法下界与参数化复杂度结论都以 ETH 或更强的 SETH 为假设，假设被推翻意味着这些结论失去条件性依据。但评论者指出，论文自身的表述并不推出一般 NP 问题存在次指数时间算法，因为 2^o(n) 的运行时间界无法在一般多项式时间归约下传递。该结果目前仅为预印本，尚未经同行评审验证。

「社区讨论」 评论者 cochne 强调该结果不意味着 NP 属于次指数时间，并引用了论文中关于多项式归约下时间界不传递的说明。criemen 询问该证明方法是否有直接的 SAT 求解应用，还是仅停留在最坏情况的理论层面；strommec 则追问若证明成立，是否意味着自注意力可以做到次二次时间，反映出读者对结论外推存在不同理解。

西北大学团队将单个正电子囚禁数月 ⭐️ 8.0/10

美国西北大学 Gerald Gabrielse 团队利用单正电子量子回旋仪，在接近绝对零度的真空中以电磁场将单个正电子（电子的反物质对应体）囚禁数月，且过程中不摧毁粒子，从而可以反复进行非破坏性测量。据美国物理学会的说法，新装置有望把反物质测量精度提升约 30 倍。目前实验尚未发现正电子与电子之间存在意外差异；若未来测出两者对磁场的响应不同，解释物质与反物质行为的定律就需要改写。该消息来自 Telegram 频道的简要转述，并非原始论文。

telegram · zaihuapd · 10月26日 06:06

「背景」 正电子是电子的反物质对应体，与电子相遇会湮灭，因此通常极难长时间保存和反复测量。此次实验将单个正电子囚禁在约 0.3 K 的电磁阱中，并冷却至回旋量子基态，从而实现对同一粒子的非破坏性重复观测。

「影响」 可反复测量的单粒子囚禁方式，为长期、非破坏性的正电子测量提供了条件；若约 30 倍的精度提升能够实现，将有助于检验正电子与电子在磁场响应上是否存在差异。不过这一精度数字目前只是美国物理学会给出的预期，尚非已发表的实测结果。

Simon Willison 对 Jeff Lindsay 的 webframe 做了实操评估。这个 Go 工具把 URL 或本地文件放进隐藏的无头 WebView 中执行，将 console.log() 输出到标准输出、异常输出到标准错误。它基于 glaze 库调用系统浏览器（macOS 的 WKWebView、Linux 的 WebKitGTK、Windows 的 WebView2），因此无需自带浏览器引擎。Willison 让 Claude Opus 5.5 按 shot-scraper javascript 的使用模式测试，并评估其作为网页抓取工具和沙箱工具的潜力；原文内容被截断，具体测试结论未完整呈现。

rss · Simon Willison · 10月26日 16:15

「背景」 webframe 由 Jeff Lindsay 开发，用 Go 编写，底层依赖 glaze 库。glaze 是 Go 的桌面 WebView 绑定，通过 purego 实现纯 Go 移植，不引入 CGo；它调用操作系统自带的 WebView 框架——macOS 上的 WKWebView、Linux 上的 WebKitGTK、Windows 上的 WebView2——因此无需打包浏览器引擎。Simon Willison 将它与自己的 shot-scraper javascript 工具作对比，后者基于 Playwright，体积更大。

「对使用者的实际影响」 对已经用 shot-scraper 或 Playwright 做页面脚本执行的开发者来说，webframe 的差异在于不捆绑浏览器引擎，而是调用系统自带的 WKWebView、WebKitGTK 或 WebView2，因此安装体积更小、依赖更少。代价是行为取决于目标机器上的系统浏览器版本，跨平台一致性需要自行验证；该评估基于作者让 Claude Opus 5.5 实际运行并搭建原型后形成的报告，并非独立基准测试。
